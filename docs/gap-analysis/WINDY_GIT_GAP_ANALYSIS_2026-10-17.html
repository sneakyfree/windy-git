The short version
  • The verification half is real. CI for private repos (G7) is green: 36 repos, 2,827 runs in 7 days, red checks on GitHub PRs. Hosting, Gitea, backups and restore drills are mostly green.
  • The product half is mostly not started. The shelter (G5, the planned v0 product), agent tokens and provenance (G6, G9), the MCP surface (G8) and the model hub (G10) are mostly red.
  • The biggest unblocker is agent identity. The ES256 agent verifier (G3.2) is missing, so agent auth fails closed. That keeps G3.3, G6.3, G8 and G9 red.
  • Cheap wins: the canonical-domains lint in this repo (G0.10), a gpu runner label (G7.1), mirror-lag alerts (G11.2), redeploying the API image so /version matches main (G12.7).
  • Grant-gated: the model hub (§7.7), opening to non-Grant users (R0→R1), and any pricing.
